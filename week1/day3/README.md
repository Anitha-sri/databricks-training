# Day 3 - SQL Joins Assignment

## Introduction
This assignment focuses on understanding and implementing different types of SQL joins using a simple online learning platform database. The exercises cover LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, and CROSS JOIN concepts to retrieve matching and unmatched records between multiple tables.

## Topics Covered
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN
- CROSS JOIN

## Tables Used
- students
- courses
- instructors
- enrollments

## Tasks Completed
1. Display students with enrolled courses
2. Find courses with no enrollments
3. Display instructors with courses
4. Find courses without instructors
5. RIGHT JOIN examples
6. Find students without enrollments
7. FULL OUTER JOIN examples
8. Find unused courses
9. FULL OUTER JOIN between instructors and courses
10. Student, course, instructor report
11. CROSS JOIN bonus challenge

## Conclusion
Through this assignment, different SQL join operations were practiced to understand how data can be combined across multiple tables. These queries help in handling matched and unmatched records effectively, which is an important concept in database management and real-world SQL applications.
