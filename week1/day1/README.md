# SQL Practice Queries (1–65)

This repository contains 65 SQL practice queries covering basic to advanced SQL concepts using Employee, Department, and Project tables.

The queries were practiced using MySQL and DB-Fiddle to improve SQL problem-solving skills and database query writing.
