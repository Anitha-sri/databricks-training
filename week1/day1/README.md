# SQL Practice Queries (1–15)

## Overview

This repository contains the first 15 SQL practice queries covering basic SQL concepts using Employee and Department tables.

The queries were practiced using MySQL and DB-Fiddle to improve SQL query writing and understanding of database operations.

---

## Topics Covered

### Basic Queries

* SELECT statements
* WHERE conditions
* Filtering records
* Simple JOIN queries

### String Queries

* LIKE operator
* Pattern matching
* LENGTH function

### Date Queries

* YEAR()
* MONTH()
* Date comparisons

---

## Database Tables Used

### Employee Table

Stores employee details such as:

* Employee ID
* Name
* Age
* Salary
* Department ID
* Hire Date

### Department Table

Stores department information.
