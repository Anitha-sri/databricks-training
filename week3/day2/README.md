# PySpark Exercises - 1

This repository contains beginner-friendly PySpark DataFrame practice exercises using a sample employee dataset. The examples focus on learning fundamental DataFrame operations that are commonly used in data engineering and data analysis.

## Contents

- Sample Employee DataFrame
- DataFrame Creation
- Select Operations
- Column Selection
- Column Aliasing
- Filter / Where Conditions
- Multiple Condition Filtering
- String-Based Filters
- Date-Based Filters
- Numeric Filters

## Topics Covered

- `select()`
- `filter()`
- `where()`
- `col()`
- `alias()`
- `isin()`
- `startswith()`
- `endswith()`
- `contains()`
- Logical Operators (`&`, `|`)
- DataFrame Column Operations

## Dataset

The sample dataset contains employee information, including:

- Employee ID
- Employee Name
- Age
- City
- Designation
- Salary
- Joining Date
- Department

## Purpose

This project is intended for practicing basic PySpark DataFrame operations. It provides hands-on examples to help build a strong foundation before moving on to advanced transformations, aggregations, joins, and window functions.

## Learning Outcome

After completing these exercises, you will be able to:

- Create PySpark DataFrames
- Select specific columns
- Rename columns using aliases
- Apply filtering conditions
- Work with string and numeric functions
- Query DataFrames efficiently
- Build confidence with basic PySpark transformations
