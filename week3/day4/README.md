
# SQL to PySpark - Phase 3 Final ETL & Pipeline

This repository contains the final phase of SQL to PySpark practice, focusing on building complete ETL workflows. The exercises demonstrate how to read data, clean datasets, perform transformations, generate business reports, and implement reusable data engineering pipelines using PySpark.

## Repository Structure

```
day4/
├── phase3_questions.txt
├── phase3_sql_solutions.sql
├── phase3_pyspark_solutions.py
├── customers.csv
├── orders.csv
└── README.md
```

## Files

| File | Description |
|------|-------------|
| `phase3_questions.txt` | Practice questions and ETL pipeline exercises |
| `phase3_sql_solutions.sql` | SQL solutions for all business scenarios |
| `phase3_pyspark_solutions.py` | Equivalent PySpark DataFrame implementations |
| `customers.csv` | Sample customer dataset |
| `orders.csv` | Sample sales/order dataset |

## Topics Covered

- Reading CSV Files
- Data Ingestion
- Data Cleaning
- Handling Null Values
- Filtering Records
- Aggregations
- Joins
- Group By Operations
- Business Reporting
- ETL Pipeline Development
- SQL to PySpark Conversion

## Business Scenarios

- Daily Sales Analysis
- City-wise Revenue Analysis
- Repeat Customer Identification
- Highest Spending Customer by City
- Final Reporting Table Generation

## ETL Workflow

### Extract
- Read data from CSV files.

### Transform
- Handle missing values.
- Filter invalid records.
- Join datasets.
- Perform aggregations and business calculations.

### Load
- Generate final reports and display transformed data.

## Goal

The objective of this practice pack is to develop an ETL mindset by translating SQL queries into PySpark DataFrame transformations and combining them into reusable data engineering pipelines.

## Prerequisites

- Basic SQL
- Python
- PySpark
- Apache Spark
