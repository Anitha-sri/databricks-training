# SQL to PySpark - Phase 2 Bridge Pack

This repository contains practice exercises for converting SQL queries into equivalent PySpark DataFrame transformations. The exercises focus on solving common business scenarios using joins, aggregations, filtering, sorting, and basic data cleaning.

## Repository Structure

```
day3/
├── phase2_questions.txt
├── phase2_sql_solutions.sql
├── phase2_pyspark_solutions.py
├── customers.csv
└── sales.csv
```

## Files

| File | Description |
|------|-------------|
| `phase2_questions.txt` | Practice questions and exercise instructions |
| `phase2_sql_solutions.sql` | SQL solutions for all practice exercises |
| `phase2_pyspark_solutions.py` | Equivalent PySpark DataFrame solutions |
| `customers.csv` | Sample customer dataset |
| `sales.csv` | Sample sales dataset |

## Topics Covered

- Reading CSV files
- Data Cleaning
- Filtering
- Inner Join
- Left Join
- Left Anti Join
- Group By
- Aggregations
- Sorting
- SQL to PySpark Conversion

## Business Scenarios

- Customer Spend Analysis
- Top Customers
- Customers Without Orders
- City-wise Revenue
- Average Order Amount
- Frequent Customers
- Customer Ranking by Total Spend

## Goal

The goal of this practice pack is to strengthen the understanding of how SQL queries translate into PySpark DataFrame operations while solving real-world data engineering problems.

## Prerequisites

- Basic SQL
- Basic Python
- PySpark
- Apache Spark
