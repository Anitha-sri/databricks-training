# SQL Number Manipulation Functions

This repository contains SQL practice examples for Number Manipulation Functions in MySQL.

## Topics Covered

* ABS()
* ROUND()
* CEIL()
* FLOOR()
* TRUNCATE()
* MOD()
* POWER()
* POW()
* SQRT()
* SIGN()
* RAND()
* FORMAT()
* GREATEST()
* LEAST()
