# MySQL String Functions Practice

This repository contains MySQL string function examples with sample data and practice queries. It is created for beginners and students who want to learn and practice string functions in MySQL.

## Topics Covered

* `length()`
* `char_length()`
* `upper()`
* `lower()`
* `trim()`
* `ltrim()`
* `rtrim()`
* `concat()`
* `concat_ws()`
* `substring()`
* `substr()`
* `left()`
* `right()`
* `instr()`
* `locate()`
* `replace()`
* `reverse()`
* `lpad()`
* `rpad()`
* `ifnull()`
* `coalesce()`
* `find_in_set()`
