# Generate 20,000 Records Using PySpark

## Step 1: Import Required Libraries

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import rand, when, col, expr
import random
```

## Step 2: Create Spark Session

```python
spark = SparkSession.builder.appName("DataGenerator").getOrCreate()
```

## Step 3: Sample Values

```python
products = ["Laptop", "Mobile", "Tablet", "Watch", "Headphones"]
categories = ["Electronics", "Accessories"]
cities = ["Hyderabad", "Chennai", "Bangalore", "Mumbai", "Delhi", None]
```

## Step 4: Generate 20,000 Records

```python
data = []

for i in range(20000):
    order_id = random.randint(1000, 3000)      # duplicates + updates
    customer_id = f"C{random.randint(1, 500)}"
    product = random.choice(products)
    category = random.choice(categories)
    city = random.choice(cities)
    date = f"2024-01-{random.randint(1,28):02d}"

    # introduce null and negative values
    amount = random.choice([
        random.randint(1000, 60000),
        None,
        -random.randint(1000, 5000)
    ])

    quantity = random.randint(1, 5)

    data.append((
        order_id,
        customer_id,
        product,
        category,
        city,
        date,
        amount,
        quantity
    ))
```

## Step 5: Create DataFrame

```python
columns = [
    "order_id",
    "customer_id",
    "product",
    "category",
    "city",
    "date",
    "amount",
    "quantity"
]

df = spark.createDataFrame(data, columns)
```

## Step 6: Display Sample Records

```python
df.show(5)
```

## Step 7: Save as CSV (Bronze Layer Input)

```python
df.write \
    .mode("overwrite") \
    .option("header", True) \
    .csv("flipkart_raw_data")
```

## Data Quality Issues Included

This dataset intentionally contains real-world data quality issues for practice.

### NULL Values

- amount
- city

### Duplicate Records

- Same `order_id` appears multiple times

### Negative Values

- Invalid sales amounts

### Updates

- Same `order_id` with different dates

These issues help students practice data cleaning and transformations using PySpark.
