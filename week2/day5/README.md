# SQL NULL Functions Practice

This repository contains SQL NULL function examples with sample tables, sample data, and practice queries. It is designed for beginners and students to understand how NULL values are handled in SQL.

## Topics Covered

* `is null`
* `is not null`
* `isnull()`
* `coalesce()`
* `nullif()`

## What's Included

* Sample tables
* Sample data
* Practice questions
* SQL solutions
* Basic to advanced examples
* Real-time scenarios

## Practice Levels

* **Level 1:** Basic NULL queries
* **Level 2:** `isnull()`
* **Level 3:** `coalesce()`
* **Level 4:** `nullif()`
* **Level 5:** Real-time scenarios
* **Level 6:** Advanced practice

## How to Use

1. Create the sample tables.
2. Insert the sample data.
3. Run each query.
4. Understand the output.
5. Practice by modifying the queries.

Happy Learning! 🚀
